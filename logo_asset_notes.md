Logo asset inspection notes

Primary source reviewed: assets/icons/app-icon-512.png (512x512 PNG). It is a square app icon with a light gray/white atmospheric background, black NOWSSB wordmark, two human figures, and white flowing hair-like forms. It is not a clean transparent mascot-only mark.

Secondary source reviewed: assets/icons/logo-disc.webp (320x320 WEBP). It is a circular version of the same NOWSSB artwork with a black outer background and reflective disc edge. It is also not a clean transparent mascot-only mark.

Production decision: use logo-disc.webp as the hero reference plane, preserve it as a flat/alpha-compatible branded disc, and build a beveled/extruded circular emblem around it. Add a metallic dark backing, amber emissive rim, particle dissolve, wobble spin, camera dolly/orbit, volumetric backlight, shockwave torus, and pulse scale. Blender is not installed in the current sandbox, so deliver a ready-to-run Blender Python script and scene setup instructions; render validation can be performed in Blender locally.
